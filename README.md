# Домашнее задание к работе 4

## Условие задачи

Два робота (А и В) выполняют задания. Они начинают работу одновременно только в том случае, если номера их заданий таковы, что ровно один из номеров является чётным. Записать условие начала работы.

## 1. Алгоритм решения

1. НАЧАЛО
2. Ввести числа А и В (номера заданий роботов А и В).
3. Вычислить условие: (A % 2 == 0 && B % 2 != 0) || (A % 2 != 0 && B % 2 == 0).
4. ЕСЛИ условие верно:
   - Роботы начинают работу = ДА
   Иначе:
   - Роботы начинают работу = НЕТ
5. Вывести результат (1 — да, 0 — нет).
6. КОНЕЦ

## 2. Реализация программы

Код программы находится в файле `main.c` в этом же репозитории.

## 3. Результаты работы программы

```text
введите номер задания первого робота: 4
введите номер задания второго робота: 7
роботы начинают работу одновременно
```
