## Условие задачи

Два робота (А и В) выполняют задания. Они начинают работу одновременно только в том случае, если номера их заданий таковы, что ровно один из номеров является чётным. Записать условие начала работы.

## 1. Алгоритм и блок-схема

**Алгоритм решения:**
1. НАЧАЛО
2. Ввести числа А и В (номера заданий роботов А и В)
3. Проверить условие: (А четное И В нечетное) ИЛИ (А нечетное И В четное)
4. ЕСЛИ условие верно:
   - Роботы начинают работу = ДА
   Иначе:
   - Роботы начинают работу = НЕТ
5. Вывести результат (1 — да, 0 — нет)
6. КОНЕЦ
